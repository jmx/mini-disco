# Mini Disco

Mini Disco is a Linux-first command-line and terminal UI application for working with NetMD hardware and inserted MiniDisc media.

## Language

**NetMD device**:
A USB-connected MiniDisc-capable recorder or deck that speaks the NetMD protocol.
_Avoid_: player, recorder, unit, hardware

**Disc**:
The removable MiniDisc media currently inserted in a NetMD device.
_Avoid_: media, album

**Track**:
One recorded audio item on a disc, identified by its disc-local track index and optional title metadata.
_Avoid_: song, file

**Group**:
NetMD metadata that names a contiguous collection of tracks on a disc.
_Avoid_: folder, playlist
